# KinAssist (CarePointer) - Remote Elderly Assistance PRD Version: 2.0.0 | Status: Engineering-Ready ## Product Overview KinAssist transforms remote elderly family smartphone assistance into a 1-Tap Visual Guidance Bridge. Instead of intrusive full-device takeover or agonizing voice-only calls, KinAssist pairs seniors with caregivers via low-latency WebRTC screen sharing and an interactive luminous pointer overlay. ## Key Screens to Design 1. **Senior Mode - 1-Tap SOS Ready Screen**: High contrast, tactile emergency request centerpiece, dignified Scandinavian dark luxury design, large typography, paired caregiver status pill, device telemetry. 2. **Senior Mode - Active In-Session & Overlay Experience**: Active guidance session showing floating pill ("Connected with Rahul • Tap to End"), live luminous pointer target ripple overlaying parent screen/settings with voice intercom indicator. 3. **Helper Mode - Remote Assist Dashboard & Live Canvas**: Caregiver interface featuring parent device mirror, interactive pointer dock (Pointer, Circle Doodle, Steps, Rescue Back/Home/Notifications), live audio waveform, parent device telemetry (battery, signal, 42ms latency). 4. **Helper Mode - Active Guidance & Anti-Scam Privacy Shield / Telemetry**: Demonstrates helper placing pointers and the Guardian Privacy Blackout ("Protected App: Screen Paused for Privacy") safeguarding sensitive data.
